## 使用变化

- 新克隆默认使用独立 `uploads` 卷。此前使用外部课程图片目录的用户，需要自行迁入需要的图片；本次未搬动或删除任何既有外部目录/数据卷。
- `.env.example` 用于本地 Compose；IDE 运行需要分别设置 Spring 环境变量，根目录 `.env` 不会由 Spring Boot 自动载入。
- 轻量云端发布仍需先用当前源码构建 JAR，再运行打包脚本；不上传旧发布包。
- 已有学习代码的上游历史保留，目标 GitHub 地址使用命名 remote 管理；不向原上游推送。
